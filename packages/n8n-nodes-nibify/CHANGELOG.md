# Changelog

## 0.1.0

The first release of the node: **Ask & Wait**, **Send Notification**, **Cancel** and **Nudge**. `0.0.1` and `0.0.2` were empty placeholders.

**Surfaces are written for the Nibify catalog v2, which is A2UI 1.0.** A surface pasted in **Composition: JSON** binds with `{"@path": "/note"}` where A2UI 0.9 wrote `{"path": "/note"}`, titles with `"text": "#### Title"` where it wrote `"variant": "h4"`, and checks a field with `"@checks"` where it wrote `"validationRegexp"`. **Composition: Simple** writes the title as a Markdown heading.
