# @nibify/sdk

**Placeholder — non ancora funzionante.** Il nome è pubblicato per riservare lo scope; l'SDK vero arriva più avanti.

Nibify manda una richiesta interattiva a un umano — una card con bottoni e campi, su iPhone — e restituisce la risposta all'agente che l'ha chiesta. L'SDK ridurrà tutto questo a `ask()` e `notify()`.
